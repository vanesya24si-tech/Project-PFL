================================================================================
          WALKTHROUGH: INTEGRASI SUPABASE AUTH & ROLE - NETTO LAUNDRY
================================================================================

Dokumen ini menjelaskan daftar perubahan lengkap, fungsi masing-masing berkas,
serta langkah-langkah panduan untuk mengaktifkan fitur pendaftaran (Register),
masuk sesi (Login), pemulihan sandi (Forgot Password), dan pembagian peran 
(Role-Based Access Control) antara Admin dan Customer secara reaktif.

--------------------------------------------------------------------------------
1. DAFTAR PERUBAHAN DAN FUNGSINYA (WHAT CHANGED & WHAT IT DOES)
--------------------------------------------------------------------------------

A. supabase_schema.sql (Dibuat baru di root proyek)
   - Fungsi: Kumpulan perintah SQL untuk dijalankan di dashboard Supabase.
   - Perubahan: 
     * Membuat tabel "public.profiles" untuk menyimpan info tambahan user.
     * Menambahkan kolom "role" dengan batasan nilai ('admin' atau 'customer').
     * Membuat trigger otomatis "on_auth_user_created" yang akan menyalin data 
       setiap kali ada user baru mendaftar di Supabase Auth ke tabel profiles.
     * Mengatur sistem keamanan RLS (Row Level Security) agar profil aman.

B. .env & .env.example (Dibuat baru di root proyek)
   - Fungsi: Berkas konfigurasi untuk menyimpan kredensial Supabase Anda.
   - Perubahan:
     * Menyediakan variabel "VITE_SUPABASE_URL" dan "VITE_SUPABASE_ANON_KEY".
     * .env digunakan secara lokal, sementara .env.example sebagai template.

C. src/utils/supabaseClient.js (Dibuat baru)
   - Fungsi: Menginisialisasi koneksi SDK Supabase dengan aplikasi React.
   - Perubahan:
     * Membaca variabel kredensial dari berkas .env.
     * Memberikan peringatan log di konsol browser jika kredensial belum diisi, 
       sehingga aplikasi tidak mengalami crash/error saat dijalankan pertama kali.

D. src/utils/AuthContext.jsx (Dibuat baru)
   - Fungsi: Wadah pusat (React Context & Hook) untuk mengelola status masuk sesi.
   - Perubahan:
     * Menyediakan state "user", "session", "loading", dan "role" reaktif global.
     * Menyediakan fungsi asinkron siap pakai:
       - login(email, password) -> Untuk otentikasi masuk.
       - register(email, password, name, role) -> Untuk pendaftaran dinamis.
       - logout() -> Untuk keluar sesi dengan bersih.
       - resetPassword(email) -> Untuk mengirim link pemulihan sandi.
     * Memantau perubahan status sesi otomatis via "onAuthStateChange".

E. src/main.jsx (Dimodifikasi)
   - Fungsi: Bootstrapping / Entry Point aplikasi React.
   - Perubahan:
     * Mengimpor "AuthProvider" dan membungkus komponen "<App />" agar seluruh 
       halaman di bawahnya dapat menggunakan hook "useAuth()" secara reaktif.

F. src/App.jsx (Dimodifikasi)
   - Fungsi: Konfigurasi rute (Routing) dan proteksi halaman (Route Guard).
   - Perubahan:
     * Menyederhanakan "ProtectedRoute" menggunakan data "user" dan "loading" 
       langsung dari AuthContext.
     * Menghapus semua kode manual useEffect listener sesi lama agar performa 
       aplikasi lebih ringan dan terpusat.

G. src/pages/auth/Register.jsx (Dimodifikasi)
   - Fungsi: Halaman pendaftaran admin atau customer baru.
   - Perubahan:
     * Menambahkan dropdown input "Pilih Peran (Role)" dengan opsi Customer/Admin.
     * Mengintegrasikan fungsi "register" dari AuthContext.
     * Membuat penanganan error (error handling) yang sangat aman. Jika terjadi 
       kegagalan koneksi/DB, aplikasi akan memberikan pesan instruksi yang jelas.
     * Menambahkan loader spinner dan menonaktifkan tombol/input saat mendaftar.

H. src/pages/auth/Login.jsx (Dimodifikasi)
   - Fungsi: Halaman masuk aplikasi.
   - Perubahan:
     * Mengintegrasikan fungsi "login" dari AuthContext.
     * Meningkatkan keamanan error catching agar menampilkan pesan ramah pengguna.
     * Menonaktifkan tombol ketika sedang memproses masuk (loading state).

I. src/pages/auth/Forgot.jsx (Dimodifikasi)
   - Fungsi: Halaman pemulihan kata sandi.
   - Perubahan:
     * Mengintegrasikan fungsi "resetPassword" dari AuthContext.
     * Menampilkan pesan sukses/gagal secara visual yang interaktif.

J. src/layouts/MainLayout.jsx & src/components/Header.jsx (Dimodifikasi)
   - Fungsi: Tata letak utama dan header navigasi portal.
   - Perubahan:
     * Memperbarui fungsi keluar sesi ("handleLogout") agar memanggil "logout()" 
       dari AuthContext secara asinkron sebelum berpindah ke halaman login.

--------------------------------------------------------------------------------
2. LANGKAH-LANGKAH PENGAKTIFAN (STEP-BY-STEP SETUP GUIDE)
--------------------------------------------------------------------------------

LANGKAH 1: MENJALANKAN SQL DI DASHBOARD SUPABASE
1. Masuk ke dashboard Supabase Anda (https://supabase.com).
2. Pilih proyek Anda, lalu klik menu "SQL Editor" di bilah menu samping kiri.
3. Klik "+ New query" (Kueri Baru).
4. Buka berkas "supabase_schema.sql" di root proyek Anda, salin (copy) semua 
   isinya, lalu tempel (paste) ke SQL Editor Supabase.
5. Klik tombol "Run" (Jalankan) di pojok kanan bawah editor.
   * Catatan: Query ini aman dijalankan berulang kali (idempotent) karena sudah 
     dilengkapi dengan fitur pembersihan otomatis untuk RLS Policy dan trigger.

LANGKAH 2: MENGISI KREDENSIAL API DI BERKAS .ENV
1. Buka berkas ".env" di root proyek Anda.
2. Ganti nilai placeholder dengan kredensial API Supabase asli Anda:
   - VITE_SUPABASE_URL = (Salin URL Proyek dari Supabase -> Settings -> API)
   - VITE_SUPABASE_ANON_KEY = (Salin Anon Key dari Supabase -> Settings -> API)
3. Simpan (save) berkas tersebut.

LANGKAH 3: MENJALANKAN APLIKASI
1. Jalankan perintah berikut di terminal/PowerShell Anda untuk memulai:
   npm run dev
2. Buka halaman Register, pilih Peran "Admin" atau "Customer", lalu lakukan pendaftaran.
3. Periksa menu "Table Editor" pada tabel "profiles" di Supabase Anda untuk 
   memastikan kolom "role" telah terisi otomatis sesuai pilihan pendaftaran Anda.

LANGKAH 4 (OPSIONAL): MENGGUNAKAN SUPABASE CLI SECARA LOKAL
1. Pasang Supabase CLI ke proyek Anda:
   npm install supabase --save-dev
2. Untuk menginisialisasi konfigurasi Supabase lokal:
   npx supabase init
3. Untuk login ke akun Supabase Anda:
   npx supabase login
4. Untuk menautkan ke proyek cloud Supabase Anda:
   npx supabase link --project-ref <referensi-proyek-anda>
